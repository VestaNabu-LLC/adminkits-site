# adminkits.monaidea.com

Admin Kits, a Monaidea category: practical workbooks for the people who run their team's software. Served by GitHub Pages from `main` (custom domain in `CNAME`). Plain HTML and CSS, nothing that runs: no scripts on a category's site (decision #52 of the StandAloneHarnessed project). `style.css` is a copy of www.monaidea.com's.

Made by hand for the first product, before the platform publishes categories itself (the plan's C2), which then takes this address over with the same paths.
